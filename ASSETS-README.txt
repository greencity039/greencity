GREENCITY ASSETS

The website expects these existing asset paths:

images/
  greencity-logo.png
  greencity-hero.jpg
  bin-washing.jpg

videos/
  bin-washing.mp4

If your original GreenCity images/video use different filenames, keep the
existing filenames and update only the matching src/poster paths in index.html.

The code files in this refresh do not contain your original image/video files,
so those assets must be uploaded separately to GitHub.
